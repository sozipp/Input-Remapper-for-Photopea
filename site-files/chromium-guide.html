Chromium / Chrome
install guide

Chrome · Edge · Opera · Brave · any Chromium-based browser.

Step 1 — Download & extract

Click below to download the extension package (chromium.zip) — the exact same build as the Firefox version.

Download chromium.zip

Trusted? Verify the source → github.com/sozipp/Input-Remapper-for-Photopea

Step 2 — Unzip it

  1. Open the downloaded chromium.zip file.
  2. Extract / Unzip it to a folder you can find again — e.g. your Desktop. Keep that folder permanently: the extension runs from it.
  3. Inside you should see manifest.json, content.js, popup.html, popup.js and an icons folder.
  4. Remember the exact path — you pick it in Step 3.

Step 3 — Load the extension

The steps are nearly identical everywhere: open the extensions page → Developer mode → Load unpacked → select the extracted folder.

● Google Chrome

1. Go to:
chrome://extensions/

2. Flip the Developer mode switch to ON (top-right).

3. Click Load unpacked.

4. Select the extracted folder from Step 2 and click Open.

> Done. Pin it with the puzzle icon and open photopea.com.

● Microsoft Edge

1. Go to:
edge://extensions/

2. Flip the Developer mode switch to ON (left sidebar, bottom).

3. Click Load unpacked.

4. Select the extracted folder and click Select Folder.

> Done. Pin it and open photopea.com.

● Opera / Opera GX

1. Go to:
opera://extensions/

2. Flip the Developer mode switch to ON (top-right).

3. Click Load unpacked.

4. Select the extracted folder and click Open.

> Done. Pin it and open photopea.com.

● Brave / Vivaldi / other Chromium

1. Extensions page — one of: brave://extensions/ or vivaldi://extensions/ (or chrome://extensions/).

2. Turn on Developer mode → Load unpacked → select the folder.

> Works the same everywhere.

You’re done — quick check

  1. Open photopea.com in that browser.
  2. Click the extension icon → flip the ON switch.
  3. Click + Add from Photopea shortcuts → pick e.g. Free Transform → press Insert on the recorder screen.
  4. Now Insert inside Photopea = Free Transform. Remap any key, mouse button, or scroll.

Note: Chromium won’t auto-sync unpacked extensions, so keep the extracted folder. To update, re-download the zip and load it again.
