Chromium / Chrome
install guide
> chrome · edge · opera · brave · any chromium-based

■ Step 1 — Download & extract

Click the button below to download the extension package (chromium.zip). It is the exact same build as the Firefox version.

▼ Download chromium.zip

trusted? verify the source → github.com/sozipp/Input-Remapper-for-Photopea

■ Step 2 — Unzip it

  • Open the downloaded chromium.zip file.
  • Extract / Unzip it to a folder you can find again — e.g. your Desktop. Keep that folder permanently: the extension runs from it.
  • Inside you should see manifest.json, content.js, popup.html, popup.js, and an icons folder. That’s the whole extension.
  • Remember the exact path — you will select it in Step 3.

■ Step 3 — Load the extension

Pick your browser below. The steps are nearly identical everywhere: open the extensions page → turn on Developer mode → Load unpacked → select the extracted folder.

◉ Google Chrome

1. Open a new tab and go to:
chrome://extensions/

2. Flip the Developer mode switch to ON (top-right corner).

3. Click the Load unpacked button that appears.

4. Select the extracted folder from Step 2 and click Open.

> DONE. Pin it with the puzzle icon and open photopea.com.

◉ Microsoft Edge

1. Open a new tab and go to:
edge://extensions/

2. Flip the Developer mode switch to ON (left sidebar, bottom).

3. Click Load unpacked.

4. Select the extracted folder from Step 2 and click Select Folder.

> DONE. Pin it and open photopea.com.

◉ Opera / Opera GX

1. Open a new tab and go to:
opera://extensions/

2. Flip the Developer mode switch to ON (top-right).

3. Click Load unpacked.

4. Select the extracted folder from Step 2 and click Open.

> DONE. Pin it and open photopea.com.

◉ Brave / Vivaldi / other Chromium

1. Open the extensions page — it is one of: brave://extensions/ or vivaldi://extensions/ (or chrome://extensions/).

2. Turn on Developer mode → Load unpacked → select the folder.

> Works the same everywhere.

■ You’re done — quick check

  • Open photopea.com in that browser.
  • Click the extension icon → flip the ON switch.
  • Click + Add from Photopea shortcuts → pick e.g. Free Transform → press Insert on the recorder screen. Done!
  • Now press Insert inside Photopea = Free Transform. Remap any key, mouse button, or scroll.

NOTE: Because Chromium won’t auto-sync unpacked extensions, keep the extracted folder around. It updates only when you re-download the zip and load it again.
