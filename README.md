# Input Remapper for Photopea

Remap **keyboard keys, mouse buttons, and scroll gestures** to Photopea shortcuts directly inside Photopea.

Made for people who want more control over Photopea's shortcuts without changing their normal keyboard or mouse behavior outside Photopea.

## ✨ Features

* ⌨️ Remap any keyboard key
* 🖱️ Remap mouse buttons
* 🖱️ Remap scroll gestures
* 🎨 Designed specifically for Photopea
* 💾 Saves remaps using browser storage
* 🔄 Enable or disable remapping anytime
* ⚡ Lightweight and simple
* 🌐 Works on Chrome-based browsers and Firefox
* 🔒 No account required
* 🚫 No data collection

## 💡 Example

You can create custom mappings such as:

```text
Ctrl + Alt + T → Insert
Mouse Button 4 → Ctrl + Z
Scroll Up → Ctrl + +
```

This can be useful when Photopea shortcuts conflict with browser or desktop shortcuts, or when you simply want a more comfortable workflow.

> **Note:** Browser extensions cannot reliably block shortcuts handled globally by the operating system before the browser receives the key event.

## 🎯 Why?

Photopea has many powerful shortcuts, but sometimes a shortcut can be difficult to press, conflict with another shortcut, or simply feel uncomfortable.

**Input Remapper for Photopea** lets you create your own input setup while keeping your normal controls unchanged outside Photopea.

## 🔐 Privacy

Input Remapper for Photopea does **not collect or transmit personal data**.

The extension only stores your settings locally using browser storage.

It runs only on:

```text
photopea.com
```
